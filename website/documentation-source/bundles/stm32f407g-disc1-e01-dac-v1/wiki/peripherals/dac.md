## Reviewed operating semantics

Applicability: STM32F407VGT6 DAC **channel1**, 12-bit right-aligned data and software triggering, with the reviewed 42 MHz PCLK1 recipe. `DAC` and `DAC1` are header aliases of one register block. Channel2/dual output, waveform generation, external triggers, DMA and interrupts have no operating contract in this addition. Implementing-author editorial review is separate from independent engineering sign-off and silicon-errata qualification.

Retrieve [[peripherals/rcc]], [[peripherals/flash]], [[peripherals/pwr]], [[peripherals/gpio]] and [[peripherals/tim]] first. Own both DAC channels before pulsing the shared DAC reset. Enable/read back RCC.APB1ENR.DACEN and assert/release APB1RSTR.DACRST, preserving unrelated bits. Every DAC access is an aligned **32-bit word**. Reset all14 registers to their reviewed zero values through the owned reset, rather than writing output/status/command registers indiscriminately. Keep reserved bits zero. Sources: rm_dac_238:page:238; rm_dac_247:page:247; rm_dac_447:page:447; exact header declarations.

Configure with EN1=EN2=0. Set TEN1=1 and TSEL1=111 (software); BOFF1=0 leaves the buffer enabled. Wave generation, amplitude, channel2, DMA and interrupt enables remain zero. TSEL cannot change with EN set. The EN bit powers the analog macrocell; the digital interface remains enabled with EN=0. Configuration alone establishes neither a safe pin connection nor an analog output. Sources: rm_dac_437:page:437; rm_dac_439:page:439; rm_dac_440:page:440; rm_dac_447 through rm_dac_449.

Before EN1, review exact board connectivity and conflicts, configure the corresponding GPIO analog input mode and establish the reference, supply and load conditions. The manual identifies PA4/PA5 as converter output pins, but this bundle does **not** add a board DAC_OUT endpoint or header mapping. Do not substitute MCU capability for a resolved board net. See [[schemas/custom_pcb_netlist]]. DS8626 gives VDDA/VREF+ in1.8–3.6 V (VREF+ <= VDDA); the reduced1.7 V exception has extra temperature/supervisor conditions and is outside this contract. Buffer-on load limits are RL>=5 kΩ and CL<=50 pF. Output swing and accuracy have additional constraints: the ideal DOR/4096 reference formula does not establish rail-to-rail or calibrated output. Sources: rm_dac_436:page:436; rm_dac_439:page:439; ds_dac_141 through ds_dac_143.

Single-transfer sequence: validate code0..4095 and a finite wait budget, establish the separately reviewed output prerequisites, write DHR12R1, then set EN1 with the configured trigger fields unchanged. Wait a bounded nominal1 ms using the reviewed exclusive TIM2 polling-delay contract; the conditional datasheet wakeup maximum is10 µs. Write literal SWTRIG1=1 to **write-only SWTRIGR**. Never read, poll or read-modify-write SWTRIGR. It clears in hardware when the holding data reaches DOR; software-trigger transfer takes **one APB1 cycle**, unlike the general external-trigger three-cycle case. Wait another bounded nominal1 ms before DOR comparison, including when the previous DOR already equals the requested code. A matching stale DOR must not bypass this wait. Sources: rm_dac_438 through rm_dac_440; rm_dac_449:page:449; rm_dac_450:page:450; ds_dac_143:page:143; reviewed TIM2 delay contract.

DOR1 is read-only: never write it. Check the complete DOR value and SR, giving errors priority over a matching code. DMAUDR1/2 are **W1C/rc_w1**. Do not use an SR read-modify-write that could erase another diagnostic; the example preserves both flags and requires an owned reset after failure. Successful verification means **digital output-latch code observed**, with `analog_settled=false`. The datasheet's settling-time row is conditioned on a **10-bit code transition** and ±4 LSB; it is not promoted to a12-bit precision guarantee. Additional waiting alone does not prove output accuracy. Sources: rm_dac_454:page:454; rm_dac_455:page:455; ds_dac_143:page:143.

Success leaves channel1 enabled under exclusive ownership. Explicit shutdown or reset is required before another one-shot transfer. Any timer failure, unexpected control word, underrun or mismatching DOR invalidates the configuration and latches reset-required. Cleanup may disable only a channel it enabled and whose control word still matches the owned contract. A changed channel2/control configuration is preserved for diagnosis, not overwritten. Every polling loop is bounded; budgets count attempts rather than elapsed wall time. Caller flags state preconditions and cannot supply missing review evidence.

The shipped example only configures the digital interface with EN1=0 and retains the integration entry in the linked ELF. Its main does not configure PA4, enable the analog converter, trigger output or claim a connected DAC load. The broad `feature_dac` and wired-output workflows remain blocked. No physical DAC output, voltage, settling or precision has been tested. See [[sources]] and [[index]].
