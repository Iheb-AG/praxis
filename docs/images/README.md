# Praxis artwork

- `praxis-banner.jpg`: the original dark PRAXIS/octopus artwork used as the repository banner.
- `praxis-logo.png`: the original octopus logo, available for project documentation.

Both files are the project author's supplied branding, copied unchanged from the artwork
already used by the documentation site. They are bundled locally so the GitHub README does
not rely on a private filesystem, an external image host or the development website.
