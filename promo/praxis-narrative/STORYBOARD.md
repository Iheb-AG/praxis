# Production storyboard

The narrative and frame-addressable plan are in SCRIPT_SHOTLIST.md. This film
implements the approved 37-second, 24 fps arc. Hook and Outro events are preserved.

PAGE: plausible low-level code needs board-specific evidence; embedded and AI
developers should see that difference and inspect the experimental Praxis project;
the intended feeling is uncertainty becoming an auditable workflow.

Inventory: original stone octopus and wordmark, charcoal/cyan documentation palette,
MCP tool activity, linked Markdown, actual Cortex-M4 compiler profile, an inspectable
artifact. The key verb is require; the control is a tool request; the success is an
accepted image and revalidation, not an assertion of correct physical firmware.

Idea candidates: an octopus transforming manuals (too generic), a montage of
peripherals (too broad), one failed IDE task becoming a source-backed build. The
third is selected: the exact retrieval gates and real build receipt make this Praxis.

World: one dark engineering workspace. The IDE reconstruction is an authored,
illustrative stage, not a capture of an installed client. Document content, tool
errors and build results are genuine captures. A subdued crop of the original
stone imagery gives the ground a material; cyan marks selection, red is confined
to the simulated fault and the actual prerequisite error. UI planes cast contact
shadows and share one spring grammar. No borrowed reference assets or soundtrack.

Hero moment: a macro tool refusal resolves into the clock/pin/peripheral route;
the same selected surface becomes the compiler input and eventually the artifact.
Only this transition gets maximum scale. At most one proof plane dominates.

Act surfaces/sound: Hook = illustrative editor/chat and simulated-target response;
Solution = actual MCP response and full-source table; Sandbox = actual C, pinned
profile, command and JSON receipt; Outro = those planes collapsing into verification,
then original monochrome mark and Praxis wordmark. All acts are silent because no
ElevenLabs key is configured. Narration remains an editable script.

Frame handoffs: 192 retains the IDE surface, 264 expands the selected document,
377 enters the source collage, 442 returns to the command surface, 568 reorganizes
that surface into outcomes, 672 collapses it, and 810 follows the verification click
into the brand lock. The last lock settles by frame 866, leaving about 0.92 seconds.

All views are deterministic functions of time. No MCU execution or flashing is
performed by the film. Existing compiler code, website and historical bundles
are not edited.
